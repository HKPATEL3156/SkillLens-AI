# SkillLensAI - Student Career Development & Job-Readiness Platform

SkillLensAI is an intelligent, full-stack student career guidance, evaluation, and recruitment platform. It leverages MERN (MongoDB, Express, React, Node.js) and a FastAPI-based Machine Learning service powered by Gemini LLM to automate resume parsing, skill assessments, job matching, and candidate evaluation.

---

## 🌟 Key Features & Modules

### 1. Resume Parsing Pipeline
* **Auto-Extraction:** Extracts structured candidate details (Name, Email, Phone, Primary Location, Technical Skills, Education history, Experience details, Project records, Certifications, Links) from PDF/DOCX resumes.
* **LLM Core:** Uses Gemini 2.5 Flash with custom output formatting to ensure parsed details do not contain hallucinations or missing data.
* **Persistent Deduplication:** Deduplicates identical uploads using SHA-256 hash checks, reusing existing resume documents when uploaded multiple times.
* **Parser States:** Tracks processing states: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`.

### 2. Proctor Quiz & Assessment Portal
* **NTA Light-Mode Theme:** Clean exam interface styled like official government portals (National Testing Agency).
* **AI Generator:** Generates custom multi-skilled question papers (MCQs and MSQs) in the background based on candidate profile.
* **Proctor Supervision:** Tab-switch tracking, window defocus monitoring, and warning prompts to enforce test integrity.
* **Autosave Checkpoints:** Periodic state saving (checkpoints) to prevent progress loss during power/connection drops.
* **Testing Mode Toggle:** A built-in toggle in the instructions modal to display/hide correct answer keys for verification.

### 3. Career Recommendations & Predictors
* **Job Prediction:** Recommendation engine predicting matching roles based on assessment scores, candidate skills, and academic SGPA history.
* **Skill Gap Analysis:** Computes differences between active candidate skills and requirements for a target role, highlighting missing tech stacks.
* **Career Analytics:** Detail assessment profile summaries generated by AI.

### 4. Recruiter & Company Portal
* **Document Auditing:** Verification workflow requiring corporate verification documents (Company Profile PDF, Certificate of Registration, Corporate Logo).
* **Job Board Management:** Form-based job posting, supporting direct PDF uploads for Job Descriptions (JD) and Company Policies.
* **Applicant Pipeline:** View applicants, view candidate details, and advance/reject applications through pipeline stages (`applied`, `shortlisted`, `rejected`, `hired`).

### 5. Administration Control Console
* **User Management:** Access list of active accounts, block/unblock users, or delete profiles.
* **Approval Pipeline:** Verify and approve/reject newly registered recruiters.
* **System Settings:** Moderation panel for posted jobs, reports, settings configuration, and admin profile management.

## 🛠️ Technology Stack
* **Frontend:** React (Vite), Tailwind CSS, Axios, React Router Dom
* **Backend:** Node.js, Express, MongoDB (Mongoose), Multer, jsonwebtoken, bcryptjs
* **ML Service:** FastAPI (Python), Uvicorn, Google GenAI SDK (Gemini 2.5 Flash), Scikit-Learn, Pandas, Numpy, Joblib, PDFPlumber, Docx2txt
* **API Documentation:** Swagger UI (`swagger-ui-express` & `swagger-jsdoc`)

## 🚀 Get Started & Local Setup

### Prerequisites
Make sure you have the following installed:
* [Node.js](https://nodejs.org/) (v16+)
* [Python](https://www.python.org/) (v3.9+)
* [MongoDB](https://www.mongodb.com/) (Local Community Server or MongoDB Atlas Account URI)
* [Gemini API Key](https://aistudio.google.com/)

---

### 1. Backend Service Setup (Node/Express)

1. Navigate to the `/backend` folder:
   ```bash
   cd backend
   ```
2. Install package dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` configuration file in the `/backend` root directory and add the following keys (fill with your own credentials):
   ```env
   MONGO_URI=mongodb://localhost:27017/skilllensai
   JWT_SECRET=your_jwt_signing_secret_key
   PORT=5000
   ```
4. Start the backend development server:
   ```bash
   npm run dev
   ```
   The backend will be running on `http://localhost:5000`.
   * **API Docs Dashboard:** Visit **`http://localhost:5000/api-docs/`** to view the interactive Swagger/OpenAPI documentation.

---

### 2. Frontend Portal Setup (React/Vite)

1. Navigate to the `/frontend` folder:
   ```bash
   cd ../frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite React development server:
   ```bash
   npm run dev
   ```
   The application dashboard will be live at **`http://localhost:5173`**.

---

### 3. Machine Learning & AI Service Setup (Python/FastAPI)

1. Navigate to the `/ml-service` folder:
   ```bash
   cd ../ml-service
   ```
2. Set up a Python virtual environment:
   * **Windows:**
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   * **macOS/Linux:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
3. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a `.env` file inside the `/ml-service` directory and configure the Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
5. Run the FastAPI server:
   ```bash
   uvicorn main:app --reload --port 8000
   ```
   The ML service endpoint will be active on **`http://localhost:8000`**.
